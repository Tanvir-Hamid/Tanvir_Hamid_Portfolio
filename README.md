# Tanvir Hamid — Portfolio

A responsive portfolio website built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — main portfolio page
- `styles.css` — responsive styling
- `script.js` — mobile menu and year
- `TanvirHamid.pdf` — CV used for the Download CV button

## Run locally
Open `index.html` in a browser.

## Deploy with GitHub Pages
1. Create a new GitHub repository (for example `tanvir-portfolio`).
2. Upload all files from this folder.
3. Go to Settings → Pages.
4. Select the `main` branch and `/root`.
5. Save and open the generated GitHub Pages URL.
